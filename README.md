# About

My journey into cybersecurity did not begin with penetration testing.

It started with networking.

Studying network architecture, routing, protocols, and infrastructure provided a deeper understanding of how modern systems communicate long before learning how they fail.

That foundation gradually evolved into network security and later into offensive security.

Today my interests extend beyond vulnerability discovery.

I enjoy designing software that helps security professionals understand systems, automate repetitive workflows, organize reconnaissance data, and transform raw information into actionable intelligence.

Instead of relying entirely on existing tooling, I prefer building my own.

Every repository represents an engineering problem before it becomes a cybersecurity project.

# HaQtor Lens

### Attack Surface Intelligence Platform

HaQtor Lens is an attack surface intelligence platform designed to transform raw reconnaissance data into structured, meaningful security intelligence.

Traditional reconnaissance often produces large volumes of disconnected information. HaQtor Lens focuses on understanding how discovered assets relate to one another before deeper analysis begins.

Instead of asking **"What assets exist?"**, the platform aims to answer:

- How are these assets connected?
- Which infrastructure is shared?
- What should be prioritized?
- Which findings deserve further investigation?

### Core Capabilities

- Asset Correlation
- Subdomain Relationship Discovery
- Infrastructure Analysis
- Attack Surface Organization
- Reconnaissance Automation
- Security Data Enrichment
- Intelligence-Oriented Workflows

### Design Goals

- Scalable architecture
- Modular processing pipeline
- High signal-to-noise ratio
- Practical workflows
- Future extensibility

# TechFinger

### Passive Technology Fingerprinting Engine

TechFinger is a passive fingerprinting engine that identifies technologies through observation rather than intrusive interaction.

Instead of performing active scans, the engine collects evidence from publicly available responses and combines multiple indicators using heuristic analysis.

This approach helps reduce unnecessary requests while still producing useful technology insights.

### Passive Evidence Sources

- HTTP Headers
- HTML Structure
- JavaScript Assets
- Cookies
- Error Pages
- Response Metadata

### Detection Capabilities

- Backend Technologies
- Framework Detection
- CMS Detection
- CDN Identification
- WAF Identification
- Server Fingerprinting
- Front-End Libraries
- JavaScript Frameworks

### Engineering Goals

- Passive by design
- Lightweight execution
- Modular detectors
- Extensible heuristics
- Readable output

# SubCorrelate

### Intelligence Layer Between Enumeration and HTTP Probing

Most reconnaissance workflows immediately transition from subdomain discovery into HTTP probing.

SubCorrelate introduces an intermediate intelligence layer that analyzes discovered assets before expensive probing begins.

By organizing and correlating reconnaissance data first, the quality of subsequent analysis can be significantly improved.

### Why It Exists

Large reconnaissance datasets often contain duplicated, low-value, or poorly prioritized assets.

SubCorrelate focuses on reducing that noise before downstream tooling processes the results.

### Benefits

- Better Prioritization
- Reduced Noise
- Improved Asset Organization
- Smarter Reconnaissance
- Higher Quality Target Selection

### Design Philosophy

Enumeration should produce intelligence rather than simply generate larger lists.
